arXiv · cs.CL June 2026
When Better Codebooks Are Not Enough: Predictive Performance and Behavioral Reliability in LLM Political Event Coding
Zixian He, Bharath Raahul Murugesan, Patrick Brandt, Yibo Hu

A study of how expert-written codebooks can be operationalized for LLM-based political event coding — a fine-grained source–target relation classification task. We find that clearer codebooks substantially improve classification accuracy, yet these gains don't fully translate into behavioral reliability: models can produce correct labels while still failing under controlled changes to label names, codebook order, and definition mappings. The work argues that codebook-guided LLM systems should be judged not just on accuracy, but on whether they preserve the coding logic that makes outputs meaningful for social-science research.
